# Changelog

## 1.0.0 — 2026-10-13

- Added complete Today, Plan, Knowledge, Stats, and Settings views with Chinese/English copy and host-theme styling.
- Added course/week editing, paste preview with batch undo, composed day plans and explicit overrides, task/subtask management, Markdown notes and relations, SM-2 cards/decks, and reading resources.
- Added Host-persisted focus transitions, local-midnight records, daily-goal streaks, a heatmap, course/tag distributions, and trend details.
- Added the authenticated learning-data API and four lifecycle-owned Agent tools. UI and tools share one durable store.
- Added validated JSON replacement import/export, preserved legacy browser backups, daily review limits, queued writes, and visible handling of uncertain persistence failures.
- Added deterministic client generation and focused tests without new dependencies. Domain algorithms and learning schemas are unchanged.
- See the [upgrade guide](docs/upgrade-guide/v0.1.0/host-data/guide.md) for data ownership and Host service requirements.
